◈ EXPERIENCIA VISUAL

Diseñado para la Oscuridad

Cuatro atmósferas cinematográficas construidas para sesiones de alta concentración. Cada pixel responde a una única temática cohesiva.

Blood Sun

Negro absoluto con acentos rojos. Inspirado en la atmósfera cinematográfica de The Batman.

Ocean Depths

Azul marino profundo para inmersión total. Diseñado para largas sesiones de concentración.

Neon Night

AMOLED puro con destellos neón. Negro total para pantallas OLED que ahorran batería.

Soft Day

Modo claro minimalista. Tonos cálidos y suaves para uso en exteriores con luz natural.
